# 用户登录和注册使用指南

## 🚀 快速开始

### 1. 访问系统
打开浏览器访问：http://localhost:5004

### 2. 注册新用户
1. 在登录页面点击"注册"标签
2. 填写用户信息：
   - 用户名：3-20个字符
   - 密码：至少6个字符
   - 确认密码：与密码一致
   - 邮箱：可选填写
3. 点击"注册账号"按钮

### 3. 登录系统
1. 在登录页面输入用户名和密码
2. 点击"登录系统"按钮
3. 成功后会跳转到主页面

### 4. 管理个人资料
1. 登录后在主页面右上角可以看到用户信息
2. 点击"👤 个人资料"查看详细信息
3. 在个人资料页面可以修改密码

### 5. 退出登录
点击"🚪 退出登录"安全退出系统

- 密码使用SHA256加密存储

- 自动重定向保护未授权访问

## 🛠️ 技术实现

- **后端**: Flask + Python
- **存储**: JSON文件
- **加密**: SHA256哈希
- **会话**: Flask Session
- **前端**: HTML5 + CSS3 + JavaScript

## 📞 使用提示

1. 注册成功后请记住用户名和密码
2. 建议使用强密码（包含字母、数字、特殊字符）
3. 定期修改密码确保安全
4. 如有问题可查看系统日志
